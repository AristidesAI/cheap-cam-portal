# photos/

Drop your images here. The main `README.md` references them by these
filenames — if you keep the names, the README's image links work
automatically. If you rename, just edit the README to match.

| Filename                     | What it should show                                                                 |
|------------------------------|-------------------------------------------------------------------------------------|
| `portal-ui.png`              | A screenshot of the running portal at `http://127.0.0.1:8888/` (browser window). |
| `aliexpress-listing.png`     | The AliExpress product page screenshot of the cam you bought.                       |
| `box-contents.jpg`           | The cam, its little USB-C-to-USB lead, and what was in the box.                     |
| `board-overview.jpg`         | The whole PCB after opening the case — SoC, sensor, WiFi module visible.            |
| `board-uart-pads.jpg`        | Close-up of the UART solder pads (TX/RX/GND).                                       |
| `ft232rl-pinout.png`         | A pin-out reference for the FT232RL USB-TTL adapter you're using.                   |
| `ft232rl-wiring.jpg`         | The FT232RL with the three wires (TX, RX, GND) soldered to the cam board.           |
| `terminal-first-boot.png`    | Screenshot of your serial-monitor showing the cam booting + `Password for login:`.  |
| `portal-filters.png`         | Optional: portal screenshot with some filters applied so the controls are visible.  |

PNG or JPG both work. Keep individual files under ~1 MB if you can —
GitHub renders large images slowly.
